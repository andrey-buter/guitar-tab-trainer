# Использование исходного кода alphaTab вместо npm пакета

Этот документ описывает, как настроить проект для использования исходного кода alphaTab из локального репозитория вместо npm пакета.

## Шаг 1: Клонирование репозитория alphaTab

Склонируйте репозиторий alphaTab рядом с проектом:

```bash
cd f:\__Projects__
git clone https://github.com/CoderLine/alphaTab.git
```

Или в любое другое место и укажите путь через переменную окружения (см. Шаг 3).

## Шаг 2: Сборка alphaTab

Перейдите в директорию alphaTab и выполните установку зависимостей и сборку:

```bash
cd alphaTab
npm install
npm run build
```

**Важно:** Убедитесь, что сборка прошла успешно и создана папка `dist` с собранными файлами.

## Шаг 3: Включение использования локального репозитория

Есть два способа включить использование локального репозитория:

### Способ 1: Автоматическое определение (если репозиторий находится в `../alphaTab`)

Если вы склонировали репозиторий в `../alphaTab` относительно проекта, система автоматически определит его наличие и будет использовать локальный код.

### Способ 2: Через переменные окружения

Если репозиторий находится в другом месте или вы хотите явно указать путь:

**Windows (PowerShell):**
```powershell
$env:USE_LOCAL_ALPHATAB="true"
$env:ALPHATAB_SOURCE_PATH="..\alphaTab"  # или другой путь
npm start
```

**Windows (CMD):**
```cmd
set USE_LOCAL_ALPHATAB=true
set ALPHATAB_SOURCE_PATH=..\alphaTab
npm start
```

**Linux/Mac:**
```bash
USE_LOCAL_ALPHATAB=true ALPHATAB_SOURCE_PATH=../alphaTab npm start
```

## Шаг 4: Запуск проекта

Запустите проект как обычно:

```bash
npm start
```

В консоли вы должны увидеть сообщение:
```
[alphaTab] Используется локальный репозиторий: ../alphaTab
[alphaTab] Webpack alias настроен: @coderline/alphatab -> .../alphaTab/dist
```

## Работа с изменениями

После внесения изменений в исходный код alphaTab:

1. Перейдите в директорию alphaTab:
   ```bash
   cd ../alphaTab
   ```

2. Пересоберите проект:
   ```bash
   npm run build
   ```

3. Вернитесь в проект и перезапустите dev-сервер (если он запущен, перезапустите его):
   ```bash
   cd ../051_alphaTabWebsite
   npm start
   ```

## Отключение локального репозитория

Чтобы вернуться к использованию npm пакета, просто не устанавливайте переменную окружения `USE_LOCAL_ALPHATAB` или установите её в `false`:

**Windows (PowerShell):**
```powershell
$env:USE_LOCAL_ALPHATAB="false"
npm start
```

**Linux/Mac:**
```bash
USE_LOCAL_ALPHATAB=false npm start
```

Или удалите/переименуйте папку с локальным репозиторием, и система автоматически переключится на npm пакет.

## Устранение проблем

### Ошибка: "Папка dist не найдена"
Убедитесь, что в репозитории alphaTab выполнен `npm run build` и папка `dist` существует.

### Ошибка: "Локальный репозиторий не найден"
Проверьте путь к репозиторию. Убедитесь, что:
- Путь указан правильно (относительно корня проекта)
- Репозиторий действительно существует по указанному пути
- В репозитории есть файл `package.json`

### Изменения не применяются
После изменения кода в alphaTab обязательно выполните `npm run build` в директории alphaTab и перезапустите dev-сервер проекта.

## Примечания

- Локальный репозиторий используется только если установлена переменная `USE_LOCAL_ALPHATAB=true` или если папка `../alphaTab` существует
- Если локальный репозиторий не найден или не собран, система автоматически переключится на npm пакет
- Все импорты `@coderline/alphatab` будут автоматически перенаправлены на локальный код через webpack alias
